- **CR1-1** — **Impact:** On a cache read after a new snapshot was persisted, the affected agent row is deleted and treated as a miss. The serializer now includes icon and responseMetadata, but StoredAgentSnapshotSchema is a strict object without either field; the server assigns responseMetadata during agent registration. **Checked:** Both the direct agent read and directory read parse with this schema, and parse failures delete the invalid row. Rows written by an older version without these fields are the counterexample and still parse. **Proof:** Source inspection; a write/read round-trip test for a snapshot with responseMetadata is proposed, not run. **Fix:** Add the new fields as optional schema members and cover the serialize/read round trip. **Gate:** Non-blocking because a daemon reconnect repopulates the row; offline cached startup remains affected.
- **CR1-2** — **Impact:** The eight locale edits add translation work for this change and leave translated copies that can go stale when English strings change under the English-only maintenance policy. **Invariant:** CLAUDE.md:12 explicitly says to update English resources only and not create or update other translations unless requested; docs/i18n.md now documents English fallback and incomplete non-English resources. **Checked:** The diff adds new keys across all eight non-English resources; the existing upstream translation scope is explicitly overridden by the fork policy. **Proof:** Source and instruction inspection; no runtime test is relevant or needed for this policy violation. **Fix:** Keep the new and changed copy in English resources only and remove these additions from the other locale files. **Gate:** Blocking because this candidate directly violates the user's explicit fork policy.
- **CR1-3** — **Impact:** A user browsing activity from another checkout can inspect or act on a same-named file in the current checkout; switching to the source workspace and reopening the file is the recovery.
