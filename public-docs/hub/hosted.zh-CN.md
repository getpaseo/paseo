# 托管 Hub {#hosted-hub}

[Paseo Hub](https://hub.paseo.sh) 是托管服务。创建账号后，你的组织默认使用 Free 方案，包含 1 个席位和每月 Agent 运行额度，无需绑卡且不会过期。需要无限运行次数、更多席位或团队邀请时，可在 **Settings → Billing** 中升级到 Pro。

Free 和 Pro 方案均包含托管的 GitHub、Linear、Slack、Discord、定时任务和入站 webhook。最新价格和方案额度见 [Hub 页面](/hub)。

登录后会打开 **Home**，提供四步引导清单：连接一个集成、连接一个 daemon、创建一个触发器并运行它。

托管 Hub 运行着与[自托管 Hub](/docs/hub/self-hosting) 相同的开源软件。托管 Hub 运维自己的 GitHub、Linear、Slack 和 Discord 应用；自托管 Hub 使用你自行创建和控制的 Provider 应用，没有任何套餐或计费。
