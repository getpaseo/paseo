## 本地 Paseo 应用和 daemon

Paseo 在你的机器上运行。它不会向我们发送分析数据、遥测数据、广告标识符或崩溃报告。

打包的桌面应用会检查 GitHub Releases 以获取更新。GitHub 会依据其自身的隐私政策，接收响应该请求所需的常规网络信息。

Claude Code、Codex 和 OpenCode 等 Agent 使用你机器上的凭据与各自的 Provider 通信。Paseo 不管理也不拦截这些 Provider API 调用。

## 官方中继

中继是可选的。为了连接你的客户端和 daemon，它会处理：

- IP 地址和连接时间
- 会话标识符和公开握手密钥
- 消息大小和总带宽
- 临时连接和路由状态

你的客户端和 daemon 使用 NaCl box 加密对应用流量进行端到端加密。中继传输的是密文，无法读取你的代码、提示词、终端输出或 Agent 对话。有效载荷仅在转发期间存在于中继内存中。我们不存储消息内容。基础设施可能会保留有限的运维日志和汇总指标，用于安全、容量规划和故障排查。

## Paseo Hub

当你创建或使用托管 Hub 账户时，我们会处理：

- 你的姓名、邮箱、账户凭据、会话、IP 地址和用户代理
- 你的组织、成员、角色、邀请和 daemon 注册信息
- 你所连接服务的标识符和凭据
- 从这些服务接收的 webhook 事件、消息、评论、附件元数据及相关上下文
- 工作流配置、触发输入、输出、执行状态、活动和审计记录
- 提供访问所需的 Stripe 客户标识符和订阅信息

除非某个工作流明确将信息发送到 Hub 或已连接的服务，否则你的代码仓库、本地文件和 Agent Provider 凭据都保留在你自己的基础设施上。Hub 不提供 AI 推理。

## 谁控制工作流数据

Paseo 控制账户、账单、安全和服务运营数据。当某个组织使用 Hub 在其工作流中处理个人数据时，由该组织决定处理数据的目的，Paseo 代表该组织处理这些数据。

## 我们为什么处理数据

我们处理数据是为了：

- 提供账户、Hub 工作流、中继连接、账单和支持
- 对用户、daemon 和已连接的服务进行身份验证
- 防止滥用并保护服务
- 维护运营和审计记录
- 履行会计、税务及其他法律义务

法律依据是履行我们与你之间的合同、我们在运营和保护服务方面的正当利益，以及遵守法律义务。

## 服务提供商

我们使用 Fly.io 提供托管基础设施，使用 Stripe 处理订阅和付款，使用 GitHub 发布软件并提供已连接的 GitHub 功能。Slack、Discord、Linear 及其他服务仅在你选择连接或使用它们时才会接收数据。

部分服务提供商可能在欧洲经济区以外处理数据。在需要时，我们会为这些传输采取适当的合同保障措施。

我们不会出售个人数据、不会与广告商共享，也不会用于训练 AI 模型。

## 保留与删除

在你的账户保持有效期间，我们会保留账户和组织数据。在提供和保护服务所需的期间内，我们会保留运营、工作流和审计记录。账单记录可能会在法律要求的会计和税务期间内保留。短期授权码和会话会自动过期。

你可以发送邮件请求删除账户。在法律要求的情况下，或在记录构成其他组织合法审计历史的一部分时，部分记录可能会保留。
