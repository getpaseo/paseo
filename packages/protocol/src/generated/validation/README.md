# Generated protocol validators

`ws-outbound.aot.ts` is generated by zod-aot from `packages/protocol/src/validation/ws-outbound-aot-source.ts`.

Run:

```bash
npm run generate:validation-aot --workspace=@getpaseo/protocol
```

The generated TypeScript is intentionally gitignored. zod-aot is exact-pinned because this is a young solo-maintainer project; keep the generated validator behind differential tests and dev-runtime comparison when upgrading it.
